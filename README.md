# Kids Puzzle

Un joc puzzle 2D pentru copii, construit cu Godot 4 pentru Web, Android și iOS.

## Prima versiune

- ecran principal;
- puzzle 3 × 3;
- control cu mouse și touch;
- snap automat al pieselor;
- detectarea finalizării;
- salvarea locală a progresului.

## Rulare

Deschide `project.godot` în Godot 4.7 și apasă **F6** sau butonul **Run Project**.
